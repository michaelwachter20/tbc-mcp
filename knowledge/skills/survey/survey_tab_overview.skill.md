> LICENSES DIFFER between users: license notes here (e.g. 'not licensed', ANZ tools) describe the machine where this was written. Check your own with `tbc_license` - search results flag commands your license lacks.
## Read first

- Read a tool's help before using it: `tbc_help action=read command=<key>` (or the topic number below).
- **Acts immediately (no panel):** Disable Redundant BS (changes data), Loop Closure (report in the browser), Processing Services (opens a web page). Ask the user first.
- The spreadsheet tools (Feature, Occupation, Vector, Optical) and Time-Based View open **view windows**, not panels. Close them when done (user preference).
- Greyed-out tools depend on project data: Process Baselines and Clear Processing need GNSS baselines, Clear Adjustment needs an adjustment, Mean Angle Residuals needs MTA data.
- Tools marked not licensed need the ANZ Toolbox and are refused automatically.
